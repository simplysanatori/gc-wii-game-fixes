# User guide

How to use an entry in Dolphin.

## Codes

1. Right-click the game, **Properties**.
2. **Gecko Codes** or **AR Codes**: tick the code. For one that is not there, **Add New Code** and paste its lines.
3. **Config > General > Enable Cheats** must be on.

A code is for one region, and often one revision, of a game. The game list shows the game ID: `GFEE01` is the USA disc, `GFEP01` the European one.

## Widescreen on GameCube

Use the game's 16:9 code and set **Graphics > Aspect Ratio** to **Force 16:9** for that game. Where there is no code, **Graphics > Enhancements > Widescreen Hack** does it for most games. Things at the sides may pop in and out.

## Texture packs

1. Unpack the pack into `Load/Textures/<game ID>/` in Dolphin's user folder.
2. Turn on **Graphics > Advanced > Load Custom Textures**.

DDS packs load faster and take less memory than PNG ones.

## Riivolution mods

Right-click the game, **Start with Riivolution Patches**, and open the mod's XML file.
